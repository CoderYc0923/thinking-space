## 一、5 个核心聚合函数（只返回一行统计结果）

| 函数    | 作用                    | 注意空值 NULL                  |
| ------- | ----------------------- | ------------------------------ |
| COUNT() | 统计行数 / 非空字段数量 | COUNT (字段) 自动忽略 NULL     |
| SUM()   | 数值求和                | NULL 不参与计算，等同于 0      |
| AVG()   | 求平均值                | 只计算有值数据，空值不计入分母 |
| MAX()   | 求最大值                | 忽略 NULL                      |
| MIN()   | 求最小值                | 忽略 NULL                      |

### COUNT 三种写法核心区别（高频面试考点）

```sql
-- 1. COUNT(*)：统计表中所有行数，包含NULL、全空行
SELECT COUNT(*) AS 总学生数 FROM student;
-- 2. COUNT(score)：统计score字段不为NULL的行数，自动忽略空值
SELECT COUNT(score) AS 有成绩学生数 FROM student;
-- 3. COUNT(DISTINCT class_id)：统计去重后的班级数量
SELECT COUNT(DISTINCT class_id) AS 总班级数 FROM student;
```



### SUM 求和

```sql
-- 所有学生总分总和
SELECT SUM(score) AS 全体总分 FROM student;
-- 只统计1班学生分数总和
SELECT SUM(score) FROM student WHERE class_id = 1;

```



### AVG 平均值

```sql
-- 全体平均分（自动忽略score=null的学生）
SELECT AVG(score) FROM student;
-- 3班男生平均分
SELECT AVG(score) FROM student WHERE class_id = 3 AND gender = '男';
```



### MAX / MIN 最大最小值

```sql
-- 最高分、最低分
SELECT MAX(score), MIN(score) FROM student; 
-- 女生最高分
SELECT MAX(score) FROM student WHERE gender = '女';
```

## 二、GROUP BY 分组、HAVING 分组过滤、完整统计实战

### GROUP BY 分组语法

1. 基础规则

   - GROUP BY 后面写**分组字段**，相同值的数据会合并为一组
   - SELECT 中**非聚合字段**，必须出现在 GROUP BY 后面（MySQL 宽松模式会报错 / 异常，规范写法强制遵守）
   - 执行顺序：FROM → WHERE 过滤原始数据 → GROUP BY 分组 → 聚合函数统计

2. 基础示例：按班级分组统计

   ```sql
   -- 按班级分组，统计每个班级人数、平均分、最高分
   SELECT class_id, COUNT(*),AVG(score),MAX(score) FROM student GROUP BY class_id;
   ```

3. 多字段分组：先按班级，再按性别分组

   ```sql
   -- 每个班级内，分别统计男生、女生数据
   SELECT
       class_id AS 班级,
       gender AS 性别,
       COUNT(*) AS 人数,
       AVG(score) AS 平均分
   FROM student
   GROUP BY class_id, gender;
   ```

   

### WHERE 和 HAVING 核心区分（本章重中之重）

1. 核心定义

   - **WHERE**：分组**之前**过滤原始数据行，**不能写聚合函数**
   - **HAVING**：分组**之后**过滤统计完成的分组结果，**只能写聚合函数**

2. 对比案例：只统计班级平均分大于 75 分的班级

   ```sql
   -- 正确写法：WHERE筛选学生，GROUP BY分组，HAVING过滤分组结果
   SELECT
       class_id AS 班级,
       COUNT(*) AS 人数,
       AVG(score) AS 平均分
   FROM student
   WHERE score IS NOT NULL -- 先过滤掉无成绩学生（原始行过滤）
   GROUP BY class_id
   HAVING AVG(score) > 75; -- 过滤平均分大于75的分组
   
   -- 错误！WHERE 不能使用聚合函数AVG()
   SELECT class_id,AVG(score) FROM student WHERE AVG(score) >75 GROUP BY class_id;
   ```

### 完整标准统计语句模板（工作通用）

```SQL
SELECT
    普通分组字段,
    聚合函数(字段) AS 统计别名
FROM 数据表
WHERE 原始行过滤条件（无聚合）
GROUP BY 分组字段1, 分组字段2
HAVING 聚合函数过滤条件
ORDER BY 统计字段 DESC/ASC;
    
```



### 题目

```sql
-- 统计每一门科目的平均分、最高分、最低分、参考人数
SELECT 
	subject,
	AVG(score) AS '平均分'
	MAX(score) AS '最高分'
	MIN(score) AS '最低分'
    COUNT(student_id) AS '参考人数'
FROM score
GROUP BY subject;


-- 筛选平均分大于 70 分的科目，按平均分降序排序
SELECT
	subject,
	AVG(score) AS '单科平均分'
FROM score
GROUP BY subject
HAVING AVG(score) > 70
ORDER BY AVG(score) DESC;
```



## 总结

1. 聚合函数 5 个：COUNT/SUM/AVG/MAX/MIN；COUNT (*) 统计所有行，COUNT (字段) 忽略 NULL
2. GROUP BY 分组规则：SELECT 中非聚合字段必须在 GROUP BY 中
3. WHERE：分组前过滤原始数据，禁止聚合函数；HAVING：分组后过滤统计结果，只能写聚合函数
4. 完整执行顺序：FROM → WHERE → GROUP BY → 聚合计算 → HAVING → SELECT → ORDER BY → LIMIT
5. 多字段分组：按书写顺序依次分层分组
