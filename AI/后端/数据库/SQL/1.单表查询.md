## 一、基础SELECT查询、别名、WHERE基础条件

### 基础查询语法

1. 语法模板

   - ```sql
     SELECT 要查询的字段 FROM 表名;
     ```

2. 写法1：查询整张表所有字段

   - ```sql
     SELECT * FROM student;
     ```

   - `*` 代表全部列，**生产环境禁止使用**，只用于本地测试

   - 缺点：多余字段会增加 IO、网络传输，性能差

3. 写法2：指定需要的字段（标准写法）

   - ```sql
     --只查询姓名、年龄、分数
     SELECT name,age,score FROM student;
     ```



### 字段别名 / 表别名 AS

1. 字段别名（查询结果列改名，中文别名加 ``）

   - ```sql
     -- AS关键字可以省略
     SELECT name AS 姓名, age 年龄, score `考试分数` FROM student;
     ```

   - 别名带中文、空格、特殊字符，必须用反引号 ``` 包裹

2. 表别名（多表查询必用，单表提前熟悉）

   - ```sql
     -- student 简写为s
     SELECT s.name, s.score FROM student s;
     ```



### 常量和简单运算

1. SQL可以在查询中包含常量值和执行简单的运算

   - 常量

     - ```sql
       SELECT class_id, '张三' AS username FROM student;
       ```

   - 简单运算 (加减乘除)

     - ```sql
       SELECT name, score * ( 1 + score ) AS fianlsCore FROM student;
       ```



### WHERE 条件过滤（核心：筛选符合条件的数据行）

| 运算符  | 含义           |
| ------- | -------------- |
| =       | 等于           |
| != / <> | 不等于         |
| > >=    | 大于、大于等于 |
| < <=    | 小于、小于等于 |

```sql
-- 查询姓名=张三的学生
SELECT name,age,scroe FROM student WHERE name = '张三';
-- 查询年龄大于18岁的学生
SELECT name,age FROM student WHERE age > 18;
-- 查询分数不等于60分的学生
SELECT name,score FROM student WHERE score != 60;
```



### 逻辑运算符 AND / OR / NOT

1. AND：且
2. OR：或
3. NOT：不

```sql
-- 1. 1班 且 分数大于90分的学生
SELECT name,score FROM student WHERE class_id = 1 AND score > 90;
-- 2. 班级1 或者 班级2 的学生
SELECT name,class_id FROM student WHERE class_id = 1 OR class_id = 2;
-- 3. NOT 取反：不是男生的学生（女生）
SELECT name, gender FROM student WHERE NOT gender = '男'; 
```

优先级：NOT > AND > OR，复杂条件建议用 `()` 包裹区分逻辑



### 空值判断 IS NULL / IS NOT NULL（高频踩坑点）

1. `NULL` 代表未知、无数据，**不能用 = NULL / != NULL 判断**
2. 判断空：`IS NULL`
3. 判断非空：`IS NOT NULL`

```sql
-- 查询分数为空的学生（马明）
SELECT name, class_id FROM student WHERE score IS NULL;
-- 查询分数不为空的学生
SELECT name, score FROM student WHERE score IS NOT NULL;
-- 错误写法，查询不出任何数据！
SELECT * FROM student WHERE score = NULL;
```



## 二、模糊匹配、范围匹配、排序 ORDER BY

### 模糊查询 LIKE 通配符 % _

1. 通配符说明

   - `%`：匹配任意长度任意字符（0 个、1 个、多个）
   - `_`：仅匹配**单个**任意字符

   ```sql
   -- 1. 姓名以"张"开头
   SELECT name FROM student WHERE name LIKE '张%';
   -- 2. 姓名包含"小"字
   SELECT name FROM student WHERE name LIKE '%小%';
   -- 3. 姓名最后一个字是"明"
   SELECT name FROM student WHERE name LIKE '%明';
   -- 4. 姓名两个字，第一个字任意，第二个是雪
   SELECT name FROM student WHERE name LIKE '_雪';
   ```

2. 范围匹配 BETWEEN ... AND ...

   - 语法：`字段 BETWEEN 最小值 AND 最大值`

   - 包含边界值（闭区间）

     ```sql
     -- 分数60 ~ 90分（包含60和90）
     SELECT name, score FROM student WHERE score BETWEEN 60 AND 90;
     ```

3. 多值匹配 IN ()

   - 当需要匹配同一个字段多个固定值时，替代多个 OR

     ```sql
     -- 查询班级1、2班的学生
     SELECT name,class_id FROM student WHERE class_id IN(1,2);
     -- 等价OR写法
     SELECT name,class_id FROM student WHERE class_id =1 OR class_id=2;
     -- NOT IN 不在指定集合内
     SELECT name,class_id FROM student WHERE class_id NOT IN(1,2);
     ```

4. 检查子查询是否返回任何行，EXISTS()

   - ```sql
      SELECT column1, column2, ...
      FROM table1
      WHERE EXISTS (SELECT column1 FROM table2 WHERE condition);
      ```
   
   - IN 检查某个值是否等于子查询返回的某个值（结果集较小，更快）
   
   - EXISTS 检查子查询是否返回任何行，不关注里面的值（结果集较大，更快）
   
5. 排序 ORDER BY

   - 基础语法

     - `ORDER BY 字段 ASC`：升序（从小到大，默认 ASC 可省略）
     - `ORDER BY 字段 DESC`：降序（从大到小）

     ```sql
     -- 1. 按分数升序（低分在前）
     SELECT name, score FROM student ORDER BY score;
     -- 2. 按分数降序（高分在前）
     SELECT name, score FROM student ORDER BY score DESC; 
     ```

   - 多字段排序

     - 优先按第一个字段排序，第一个字段值相同，再按第二个字段排序

       ```SQL
       -- 先按班级升序，同班学生分数降序
       SELECT name,score,class_id FROM student ORDER BY class_id ASC, score DESC;
       ```

       

### 三、分页 LIMIT、DISTINCT 去重、完整综合条件

### DISTINCT 去重

1. 去除查询结果中重复的数据行，写在 SELECT 后、字段前

   ```sql
   -- 查询所有不重复的班级编号
   SELECT DISTINCT class_id FROM student;
   -- 多字段去重：姓名+性别都相同才算重复
   SELECT DISTINCT name,gender FROM student;
   ```

   

### MySQL 分页 LIMIT（高频业务功能）

1. 两种写法：

   - `LIMIT 条数`：只取前 N 条

   - LIMIT 偏移量, 条数（偏移量：跳过多少行，条数：每页展示多少条）

   - 分页通用公式：偏移量 = (页码 - 1) * 每页条数

     ```sql
     -- 1. 查询前5条学生数据
     SELECT name,age,gender,class_id FROM student LIMIT 5;
     -- 2. 分页：第1页，每页4条  偏移量0，取4条
     SELECT name,age,gender,class_id FROM student LIMIT 0,4;
     -- 3. 第2页，每页4条 跳过4条，取4条
     SELECT name,age,gender,class_id FROM student LIMIT 4,4; 
     ```

     

### 完整 SQL 执行顺序（必背！理解查询底层逻辑）

1. ```SQL
   SELECT DISTINCT 字段
   FROM 表名
   WHERE 行过滤条件
   ORDER BY 排序字段
   LIMIT 偏移量,条数;
   ```

2. 执行先后顺序（从先到后）

   - FROM：找到数据表
   - WHERE：过滤原始数据行
   - SELECT：提取需要字段、DISTINCT 去重
   - ORDER BY：对筛选后的结果排序
   - LIMIT：截取分页数据

3. 重点：WHERE 先过滤，再排序分页；不能在 WHERE 中使用 SELECT 里定义的字段别名

### 综合复杂查询（融合前 2 天所有语法）

```sql
-- 需求：查询1、2班女生，分数60以上，姓名不含"小"
-- 按分数降序，只展示前5人，去重姓名
SELECT DISTINCT name 姓名,score 分数, class_id 班级
FROM student
WHERE class_id IN(1,2) AND gender = '女' AND score >= 60 AND name NOT LIKE '%小%'
ORDER BY score DESC
LIMIT 5;
```

```sql
-- 筛选条件：男生、年龄 17~19、分数不为空、班级不是 3 班
-- 姓名不能以 “周” 开头
-- 结果只展示：姓名、年龄、班级、分数，字段中文别名
-- 按分数升序排序
-- 去重同名学生
-- 分页：每页 3 条，查询第 2 页数据
SELECT DISTINCT name 姓名, age 年龄, class_id 班级, score 分数
FROM student
WHERE gender = '男'
	AND age BETWEEN 17 AND 19 
	AND score IS NOT NULL 
	AND class_id != 3
	AND name NOT LIKE '周%'
ORDER BY score ASC
LIMIT 3,3;
```



### 四、条件分支（CASE  WHEN）

1. CASE表达式允许我们在SQL中进行条件分支处理，类似if-else

   - CASE表达式可以在SELECT子句， WHERE 子句，ORDER BY等多个位置使用

   - 简单CASE表达式

     ```sql
     CASE 表达式
     	WHEN 值1 THEN 结果1
     	WHEN 值2 THEN 结果2
     	...
     	[ELSE 默认结果]
     END
     ```

   - 搜索CASE表达式

     ```sql
     CASE
     	WHEN 条件1 THEN 结果1
     	WHEN 条件2 THEN 结果2
     	...
     	[ELSE 默认结果]
     END
     ```

     ```sql
     -- 例如我们可以使用CASE表达式为课程添加难度分级
     SELECT
     	course_name,
     	price,
     	CASE
     		WHEN pirce < 100 THEN '入门级'
     		WHEN pirce >= 100 AND price < 200 THEN '进阶级'
     		WHEN pirce >= 200 THEN '专家级'
     		ELSE '未分类'
     	END AS price_level
     FROM courses;
     		
     		
     ```
