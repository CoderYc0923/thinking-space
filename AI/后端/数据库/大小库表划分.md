| 维度      | 大库                       | 小库                       |
| --------- | -------------------------- | -------------------------- |
| 数据量    | 单库 > 100GB / TB 级       | 单库 < 10GB                |
| 表数量    | 数百张以上                 | 几十张以内                 |
| QPS / TPS | 写 > 1000 / 读 > 5000      | 写 < 100 / 读 < 1000       |
| 连接数    | 数百～数千连接             | 几十连接                   |
| 索引体积  | 索引文件 > 10GB            | 索引 < 1GB                 |
| 备份恢复  | 备份耗时小时级，恢复慢     | 备份分钟级，恢复快         |
| 优化手段  | 分库分表、读写分离、中间件 | 加索引、SQL 优化即可       |
| 典型场景  | 订单库、用户库、日志库     | 配置库、字典库、后台管理库 |

| 维度     | 大表                                      | 小表                             |
| -------- | ----------------------------------------- | -------------------------------- |
| 行数     | > 1000 万行                               | < 100 万行                       |
| 表体积   | > 5GB（含索引）                           | < 500MB                          |
| 查询耗时 | 简单查询 > 100ms                          | 简单查询 < 10ms                  |
| 索引效率 | B + 树层级深，回表成本高                  | 索引层级浅，甚至全表扫也快       |
| DDL 影响 | 加字段 / 索引耗时分钟～小时级，锁表风险大 | DDL 秒级完成，影响小             |
| 写入性能 | 索引多→写入慢，大事务易阻塞               | 写入快，基本无阻塞               |
| 优化手段 | 分表、分区表、冷热分离、归档              | 加索引、优化 SQL                 |
| 典型场景 | 订单表、日志表、流水表                    | 字典表、配置表、用户表（小业务） |
