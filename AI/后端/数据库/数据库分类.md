整体分**传统关系型数据库（RDBMS）**、**NoSQL 非关系数据库**、**NewSQL 分布式数据库**、**时序 / 图 / 向量等专用数据库**四大类



## 一、关系型数据库 RDBMS（SQL 数据库）

1. 特征

   - 数据存储在**二维表**，行 + 列，严格结构化 Schema
   - 支持标准 SQL、事务 ACID、外键约束、联表 Join
   - 强一致性，适合对数据准确性、事务安全要求高的业务

2. 单机 / 集中式传统关系库

   - | 数据库     | 代表作                         | 核心优势                                                     | 短板                                             | 适用场景                                                     |
     | ---------- | ------------------------------ | ------------------------------------------------------------ | ------------------------------------------------ | ------------------------------------------------------------ |
     | MySQL      | MySQL 社区版、MariaDB、Percona | 开源免费、轻量、生态极丰富、运维简单、读写分离成熟           | 海量分片分布式原生支持弱，复杂多表查询性能一般   | 互联网业务、中小型后台、电商订单、用户系统、小程序后端、中小企业 ERP |
     | Oracle     | Oracle Database 19c/21c        | 企业级最强、极致事务、高可用 RAC、数据安全、复杂查询优化极强 | 闭源收费、硬件资源消耗大、价格昂贵               | 银行、证券、保险、运营商核心交易系统，大型政企核心业务       |
     | SQL Server | Microsoft SQL Server           | 和 Windows/.NET 生态深度集成，可视化工具完善，简单易上手     | 跨平台能力弱，Linux 版本功能受限，商业授权贵     | 传统 Windows 企业、.NET 开发系统、企业内部 OA、进销存、财务系统 |
     | PostgreSQL | Postgres                       | 开源、功能最接近 Oracle，支持复杂数据类型（JSON / 数组 / 地理）、自定义函数、强事务 | 写入性能弱于 MySQL，高并发简单查询场景资源开销高 | 复杂业务系统、GIS 地理信息、数据分析平台、电商复杂商品属性、金融中小机构 |
     | SQLite     | SQLite                         | 嵌入式、零服务、单文件数据库，无独立进程                     | 不支持高并发多写，仅本地单机使用                 | 手机 APP、桌面软件、嵌入式设备、本地缓存、小型单机工具       |

3. 分布式关系库（早期分库分表方案）

   - 基于 MySQL/PostgreSQL 改造，解决单机容量上限
   - 代表作：MyCat、Sharding-JDBC
   - 适用：传统 MySQL 业务数据量超单机，需要水平分片，又不想更换底层数据库架构



## 二、NoSQL 非关系型数据库

1. 特征

   - 无固定表结构（Schema Free），弱化事务，横向扩容简单，适配海量非结构化 / 半结构化数据；分为 4 大主流类型

2. 4 大主流类型

   - KV 键值数据库

     - 数据以 `key-value` 存储，简单查询极速，读写性能天花板

     - | 产品      | 特点                                                         | 适用场景                                                     |
       | --------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
       | Redis     | 内存 KV，支持字符串 / 哈希 / 列表 / 集合，支持持久化、发布订阅、分布式锁、缓存、延迟队列 | 业务缓存、分布式会话、限流计数器、排行榜、秒杀库存、消息队列、热点数据加速 |
       | Memcached | 纯内存缓存，极简高性能，无复杂数据结构，不持久化             | 简单热点缓存，页面静态数据缓存                               |
       | RocksDB   | 磁盘持久化 KV，LSM 树，写入性能强                            | 底层存储引擎，数据库底层、日志存储                           |

       

   - 文档数据库 Document DB

     - 数据以**JSON/BSON 文档**存储，单文档内可嵌套数组、对象，无需预定义字段

     - | 产品    | 特点                                                | 适用场景                                                     |
       | ------- | --------------------------------------------------- | ------------------------------------------------------------ |
       | MongoDB | 最主流文档库，分布式分片，灵活 schema，内置聚合查询 | 互联网用户画像、商品信息（属性不统一）、内容平台文章、小程序用户数据、物联网设备半结构化日志 |
       | CouchDB | 多版本文档，离线同步能力强                          | 移动端离线数据同步、多端协同工具                             |

       

   - 列存储数据库（宽表数据库）

     - 按**列簇**存储，海量数据压缩率极高，适合海量日志、离线大数据分析

     - | 产品      | 特点                                              | 适用场景                                                     |
       | --------- | ------------------------------------------------- | ------------------------------------------------------------ |
       | HBase     | Hadoop 生态分布式列存，万亿行海量存储，强写入吞吐 | 海量物联网时序数据、历史日志存储、离线大数据底层存储、风控海量行为日志 |
       | Cassandra | 去中心化分布式，多数据中心同步，写入性能极强      | 全球多区域业务、海量设备上报、高并发写入场景                 |

       

   - 图数据库 Graph DB

     - 存储**实体（节点）+ 关系（边）**，擅长多维度关联查询、深度关系遍历

     - | 产品       | 特点                                                | 适用场景                                                     |
       | ---------- | --------------------------------------------------- | ------------------------------------------------------------ |
       | Neo4j      | 最成熟商用图数据库，可视化图查询，Cypher 图查询语言 | 社交好友关系、知识图谱、风控团伙欺诈检测、推荐系统用户关联、供应链上下游关系 |
       | JanusGraph | 分布式大图，支持海量节点，适配大数据集群            | 超大知识图谱、全网风控关系网络、百亿级实体关联分析           |

       



## 三、NewSQL 新一代分布式关系数据库

1. 定位

   - 融合 **RDBMS 强事务 ACID + NoSQL 分布式横向扩容**，同时支持标准 SQL，解决传统数据库单机容量瓶颈。
   - 完美适配：海量数据、高并发交易、要求强一致性事务的互联网 / 金融业务

2. | 数据库      | 代表作         | 核心特性                                                     | 适用场景                                                     |
   | ----------- | -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
   | TiDB        | PingCAP TiDB   | 兼容 MySQL 协议，分布式分片，HTAP 混合负载（同时支持交易 + 分析），开源 | 互联网海量订单、支付系统、零售交易、企业海量业务数据，需要同时联机交易和实时数据分析 |
   | OceanBase   | 阿里 OceanBase | 原生分布式，金融级强一致，多副本高可用，支撑支付宝核心交易   | 银行、支付、保险核心交易系统，海量高并发在线交易业务         |
   | Spanner     | Google Spanner | 全球分布式，原子时钟实现跨地域强一致性，谷歌自研             | 跨国大型互联网企业全球统一交易数据库                         |
   | CockroachDB | Cockroach      | 兼容 PostgreSQL，去中心化多区域部署，开源                    | 多分支机构企业、跨境 SaaS 系统、分布式 ERP                   |

   



## 四、专用领域数据库（垂直场景专用）

针对单一业务场景深度优化，性能远超通用数据库

1. 时序数据库 TSDB
   - 存储**带时间戳的连续时序数据**，海量设备指标、监控指标，按时间聚合查询极强
   - 代表作：InfluxDB、Prometheus+TSDB、TimescaleDB（PostgreSQL 时序插件）、TDengine（涛思）
   - 适用场景：服务器监控指标、物联网传感器上报、电力 / 工业设备采集、车联网行驶数据、系统性能监控告警
2. 向量数据库（AI 大模型专用）
   - 存储文本 / 图片 / 音频 AI 向量嵌入，支持相似度检索，大模型知识库核心存储
   - 代表作：Milvus、Chroma、FAISS、Pinecone、PGVector（PostgreSQL 向量插件）
   - 适用场景：RAG 知识库、图片以图搜图、语义搜索、大模型对话记忆、推荐系统相似度召回
3. 数据仓库 OLAP（分析型数据库）
   - 面向海量历史数据**离线 / 实时多维分析**，不适合高频在线写入，侧重统计、报表、大数据计算
   - 代表作：ClickHouse、Hive、Spark SQL、StarRocks、Druid
   - 适用场景：企业经营报表、用户行为分析、广告投放数据分析、大数据离线统计、实时大屏指标
4. 内存数据库
   - 全数据驻留内存，微秒级读写，极致低延迟
   - 代表作：Redis（内存 KV）、VoltDB
   - 适用场景：高频实时交易、金融极速行情、高频竞价系统



## 五、数据库选型快速总结（业务场景直接对照）

1. 核心交易、财务、银行、强事务、多表关联
   - 中小业务：MySQL / PostgreSQL
   - 大型金融核心：Oracle / OceanBase
   - 海量分布式交易：TiDB
2. 缓存、热点数据、分布式锁、排行榜
   - Redis
3. 商品、用户、内容属性不固定，半结构化数据
   - MongoDB
4. 海量日志、物联网设备持续上报
   - HBase / TDengine
5. 社交关系、风控团伙、知识图谱
   - Neo4j / JanusGraph
6. AI 大模型知识库、语义检索
   - Milvus / PGVector
7. 服务器监控、传感器时序指标
   - InfluxDB / TDengine
8. 大数据分析、实时大屏、业务报表
   - ClickHouse / StarRocks
9. 手机 APP、桌面本地存储
   - SQLite
10. 海量数据 + 分布式 + 还要 SQL 事务
    - NewSQL（TiDB/OceanBase）

补充：OLTP 与 OLAP 核心区分

OLTP（联机事务处理）：RDBMS、NewSQL、Redis，高频增删改、单笔小事务、面向业务操作

OLAP（联机分析处理）：数据仓库、时序库、图数据库，海量查询、批量统计、面向数据分析
