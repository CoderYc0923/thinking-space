# L3：偶发与特殊场景

> 不是日常必现缺陷，而是 **时间 / 流量 / 发布 / 活动** 叠出来的。  
> 核心武器：**时间线对齐**。对齐后仍要回到应用 / 数据库 / 中间件修根因。

---

## 1. 何时进入本模块

常见组合：用户侧带 **U5**，或信号 **S-TIME / S-REL** 很强（可叠加 U2/U3/U4）。

- 用户说「只有整点/活动才出问题」  
- P99 **周期性**尖刺（整点、每 5/10 分钟）  
- 刚发版、刚推配置、刚扩缩容之后出现台阶  
- 「只有某一时段」，其它时间正常  

---

## 2. 子问题手册

| 子问题 | 说明 | 思路 | 关键现象 | 怎么查 |
|--------|------|------|----------|--------|
| 定时任务撞车 | 整点对账、刷缓存、报表 | 任务执行记录 vs 尖刺时间 | 整点 CPU/DB/RT 打满 | XXL-Job/Cron/K8s CronJob 历史 |
| GC 周期 | 定期 Full GC 或流量周期分配尖峰 | GC 日志时间戳对齐 P99 | 规律停顿 | `gc.log`；监控 GC pause |
| 缓存批量失效 | 同一过期时刻 | TTL 打散；看击穿 | 尖刺时 DB QPS 暴涨 | 命中率；过期策略 |
| 流量波峰 | 活动、秒杀、爬虫 | 容量与限流是否生效 | 仅高峰出错 | 网关 QPS；限流计数；4xx/5xx |
| 发布/灰度 | 新版本 Bug、坏实例 | 发布单对齐 | 发版后错误率台阶 | 按 **实例** 拆错误率；回滚决策 |
| 配置推送 | 错误开关/地址/超时 | 变更审计 | 推送后立刻异常 | 配置中心历史 |
| 扩缩容/漂移 | 冷启动、连接重建、摘流 | K8s Events | 缩容/发布时抖动 | `kubectl get events`；HPA |
| 基础设施窗口 | 备份、快照、主从切换 | 与云维护对齐 | 固定窗口故障 | RDS 备份窗口；变更公告 |
| DB 周期任务 | 统计信息、备份锁 | DBA/云日志 | 库偶发锁等待 | RDS 自治/审计 |
| 大促容量 | 热点、库存、连接不够 | 预案：限流降级扩容 | 仅活动期 | 压测报告；预案清单 |

## 4. 典型叠加

```text
整点任务 → 慢 SQL → 连接池打满 → 表象「卡死」
大促流量 → 线程池满 → Rejected → 错误率飙升
缓存雪崩 → DB → 应用超时
发版坏实例 → 仅部分 Pod 错误率高 → 像「偶发」其实是发布
```

---

## 5. 大促 / 活动最小检查单

- [ ] 网关限流、业务降级开关可用  
- [ ] DB/Redis 连接池与实例规格有余量  
- [ ] 热点 key / 热点行有方案（本地缓存、分段、限流）  
- [ ] 超时与重试：避免重试风暴  
- [ ] 监控看板：QPS、RT、错误率、池、GC、堆积  
- [ ] 回滚与扩容路径演练过
