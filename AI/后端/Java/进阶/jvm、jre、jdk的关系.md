- `JDK`是**开发工具包**
  - 它包含完整的`JRE`，
  - 编译：`javac`，运行：`java`，打包：`jar`，文档：`javadoc`
  - 排查：`jps`,`jstack`,`jmap`,`jcmd`,`jstat`...
  - 其他工具
- `JRE`是**运行环境**
  - 包含`JVM`
  - `Java`标准类库：`java.lang`,`java.util`,`java.io`,`java.net`...
  - 启动器等运行所需组件
- `JVM`是**虚拟计算机规范**，`Java虚拟机`
  - 类加载子系统`ClassLoader`
  - 运行时数据区（内存模型：堆、栈、元空间）
  - 执行引擎（解释器 + `JIT`）
  - 垃圾回收`GC`
  - `JNI`/本地方法库
  - 不同系统装不同`JVM`实现（常见`HotSpot`），所以**一次编译、到处运行**
