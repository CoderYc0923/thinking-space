RPC框架是用于实现远程过程调用的技术工具，让程序能像调用本地函数一样调用远程服务器上的方法，无需手动处理网络通信细节

## 一、概念

1. 核心作用：RPC（Remote Procedure Call）远程过程调用，本质是让一台机器上的程序调用另一台机器上的函数，调用方法和写本地代码一样简单
2. 工作流程：客户端调用方法 -> 参数序列化成字节流 -> 网络传输到服务器 -> 服务器反序列化并执行 -> 结果返回客户端
3. 好处：
   - 简化分布式系统开发，不用操心网络通信细节
   - 提高系统性能和可扩展性，能动态增减服务器节点
   - 支持多种编程语言协作 

## 二、主流框架

1. **Dubbo**：阿里巴巴开源，国内使用广泛，主要支持 Java 语言，包含服务消费者、提供者、注册中心、监控系统四个角色
2. **gRPC**‌：Google 开发，基于 HTTP/2 和 ProtoBuf 协议，‌**支持多种语言**‌，适合对带宽敏感的场景，移动端友好 
3. **Thrift**‌：Facebook 开源，‌**支持多达 25 种编程语言**‌，跨语言能力强，适合需要在多种语言间交换数据的场景 
4. **Spring Cloud**‌：整合行业优秀组件，提供微服务架构中服务治理的完整解决方案
5. **Tars**‌：腾讯开源，主要支持 C++ 语言，基于内部多年微服务实践总结
6. **Motan**‌：国内开源框架，只支持 Java，架构与 Dubbo 类似
