# 21. 反射

## 一、反射是什么？核心定义

1. 基础概念
   - **反射（Reflection）**：Java 语言在**运行期**，通过一个类的**Class 对象**，反向获取该类的全部内部信息（类名、构造方法、成员变量、成员方法、注解、父类、接口等），并且能**动态创建对象、调用方法、读写属性**的能力
2.  正反对比，更好理解
   - **正射（常规编码）**：编译期确定类，直接 `User user = new User();`，代码写死，运行前就知道要操作哪个类
   - **反射**：编译期不知道要操作哪个类，运行时才拿到类的全限定名，动态加载、操作类
3. 核心本质：Class 类（万物皆对象：类本身也是 Class 的实例对象）
   - Java 中每一个被加载的类，在 JVM 内存中都会产生一个唯一对应的 `java.lang.Class` 对象，这个对象就是反射的入口，存储了当前类所有元数据



## 二、反射的优缺点

1. 优点：
   - 高度灵活、解耦：运行时动态操作类，不需要编译期硬编码，大量框架底层依赖反射
   - 通用框架底层支撑：Spring IOC、MyBatis、SpringMVC、JUnit、序列化工具（Jackson）全部基于反射实现
2. 缺点:
   - 性能损耗：反射绕过编译期优化，运行时需要解析元数据、安全校验，创建对象 / 调用方法速度远低于直接 new、直接调用
   - 破坏封装性：反射可以强行获取、修改 `private` 私有属性、调用私有方法，违背面向对象封装原则
   - 代码可读性差、调试困难：大量字符串类名、方法名硬编码，编译期无法校验，类 / 方法改名后不会报编译错误，只会运行时报错
   - 存在安全风险：若开启反射权限，恶意代码可通过反射绕过权限校验操作内部敏感逻辑；高安全环境会限制反射



## 三、获取 Class 对象的 4 种方式（反射入口）

假设实体类：

```java
package com.demo;
public class User {
    private String username;
    public Integer age;
    // 构造器、方法省略
}
```

1. 类名.class（静态获取，推荐无实例场景）

   - 编译期即可获取 Class，无需创建对象，性能最好

   - ```java
     Class<User> clazz = User.class;
     ```

2. 对象实例.getClass ()（已有对象时使用）

   - 基于已经 new 出来的实例获取 Class，返回运行时真实类型（多态场景有效）

   - ```java
     User user = new User();
     Class<? extends User> clazz = user.getClass();
     ```

3. Class.forName ("全类名")（框架最常用，动态加载）

   - 传入类完整包名 + 类名字符串，运行时动态加载类，会触发类的**静态代码块执行**

   - ```java
     // 捕获类不存在异常 ClassNotFoundException
     Class<?> clazz = Class.forName("com.demo.User");
     ```

4. 类加载器 ClassLoader.loadClass ("全类名")

   - 通过类加载器加载类，**不会执行静态代码块**，仅加载字节码，不做类初始化

   - ```java
     ClassLoader classLoader = User.class.getClassLoader();
     Class<?> clazz = classLoader.loadClass("com.demo.User");
     ```

5. 四种方式对比总结

   | 获取方式               | 是否需要实例 | 是否初始化类（执行静态代码） | 使用场景                       |
   | ---------------------- | ------------ | ---------------------------- | ------------------------------ |
   | 类名.class             | 不需要       | 否                           | 已知类，快速获取 Class         |
   | 对象.getClass ()       | 需要实例     | 是                           | 已有对象，获取运行时类型       |
   | Class.forName (全类名) | 不需要       | 是                           | 框架动态加载类（Spring、JDBC） |
   | ClassLoader.loadClass  | 不需要       | 否                           | 仅加载字节码，延迟初始化       |



## 四、反射核心 API 体系

1. 反射全部 API 位于 `java.lang` 包，核心 4 大核心类
   - `Class`：代表类 / 接口本身，总入口
   - `Constructor`：代表构造方法，用于创建对象
   - `Field`：代表成员变量，用于读写属性值
   - `Method`：代表成员方法，用于执行方法
2. 辅助类：`Modifier`（解析权限修饰符 public/private）、`Annotation`（注解反射）



## 五、反射完整实操（创建对象、操作属性、调用方法）

前置实体类

```java
package com.demo;

public class User {
    // 私有属性
    private String username;
    // 公有属性
    public Integer age;

    // 无参构造
    public User() {
        System.out.println("无参构造执行");
    }

    // 有参构造
    public User(String username, Integer age) {
        this.username = username;
        this.age = age;
    }

    // 私有方法
    private String getInfo(String prefix) {
        return prefix + " 用户名：" + username + "，年龄：" + age;
    }

    // 公有普通方法
    public void setUsername(String username) {
        this.username = username;
    }
}
```

1. 通过反射创建类的对象

   - 两种方案：无参构造器、有参构造器

     - 无参构造创建对象（newInstance ()，JDK9 废弃）

       - JDK8 可用，要求类必须提供**public 无参构造**

       - ```java
         Class<?> clazz = Class.forName("com.demo.User");
         // 调用无参构造实例化
         User user = (User) clazz.newInstance();
         ```

       - 

     - 通用方案：获取 Constructor 构造器创建对象（推荐全版本）

       - ```java
         Class<?> clazz = Class.forName("com.demo.User");
         
         // 1. 获取public无参构造器
         Constructor<?> noArgConstructor = clazz.getConstructor();
         User user1 = (User) noArgConstructor.newInstance();
         
         // 2. 获取有参构造器：参数类型填写Class对象
         Constructor<?> argConstructor = clazz.getConstructor(String.class, Integer.class);
         User user2 = (User) argConstructor.newInstance("张三", 20);
         
         // 3. 获取私有构造器 getDeclaredConstructor，暴力访问
         // constructor.setAccessible(true) 关闭权限校验，允许访问私有
         Constructor<?> privateConstructor = clazz.getDeclaredConstructor();
         privateConstructor.setAccessible(true);
         User user3 = (User) privateConstructor.newInstance();
         ```

       - getConstructor /getDeclaredConstructor 区别

         - `getConstructor(参数类型)`：**只获取 public 公共构造器**，私有、保护、默认权限全部获取不到
         - `getDeclaredConstructor(参数类型)`：**获取本类所有构造器**（public/private/protected/default），配合 `setAccessible(true)` 突破权限限制

2. 反射操作成员变量 Field（读取、修改属性）

   - 核心两个方法

     - `getField("属性名")`：仅获取**public 公有属性**，包含父类公有字段

     - `getDeclaredField("属性名")`：仅获取**当前类所有字段**（私有、公有、保护），不包含父类字段

     - ```java
       Class<?> clazz = Class.forName("com.demo.User");
       Object userObj = clazz.getConstructor().newInstance();
       
       // 1. 操作公有字段 age
       Field ageField = clazz.getField("age");
       // 设置值
       ageField.set(userObj, 22);
       // 获取值
       Integer ageVal = (Integer) ageField.get(userObj);
       System.out.println("公有字段age：" + ageVal);
       
       // 2. 操作私有字段 username（必须暴力破解权限）
       Field usernameField = clazz.getDeclaredField("username");
       // 关键：关闭Java权限校验，允许读写私有变量
       usernameField.setAccessible(true);
       // 修改私有属性
       usernameField.set(userObj, "李四");
       // 读取私有属性
       String nameVal = (String) usernameField.get(userObj);
       System.out.println("私有字段username：" + nameVal);
       ```

3. 反射调用成员方法 Method

   - 核心两个方法

     - `getMethod("方法名", 参数类型Class数组)`：获取**public 公共方法**，包含父类所有 public 方法

     - `getDeclaredMethod("方法名", 参数类型Class数组)`：获取**本类全部方法**（public/private/protected），不含父类方法

     - ```java
       Class<?> clazz = Class.forName("com.demo.User");
       Object userObj = clazz.getConstructor().newInstance();
       Field usernameField = clazz.getDeclaredField("username");
       usernameField.setAccessible(true);
       usernameField.set(userObj, "王五");
       
       // 1. 调用公有方法 setUsername
       Method setNameMethod = clazz.getMethod("setUsername", String.class);
       // invoke(实例对象, 方法实参)
       setNameMethod.invoke(userObj, "王五修改");
       
       // 2. 调用私有方法 getInfo，暴力访问
       Method privateInfoMethod = clazz.getDeclaredMethod("getInfo", String.class);
       privateInfoMethod.setAccessible(true);
       // 执行私有方法，接收返回值
       String result = (String) privateInfoMethod.invoke(userObj, "用户信息：");
       System.out.println(result);
       ```



## 六、setAccessible (true) 深度解析（关键知识点）

1. 作用
   - 关闭 JDK 运行时的**访问权限检查**，让反射可以操作 private/protected/default 修饰的构造器、字段、方法
2. 重要特性
   - 仅对当前 Constructor/Field/Method 对象生效，不会全局修改类权限
   - 性能优化：多次反射操作同一个私有成员时，只需要设置一次 true
   - 安全管理器限制：部分容器、高安全环境会禁止 setAccessible，抛出 SecurityException





## 七、反射获取类的完整元信息（拓展）

1. 获取类基础信息

   - ```java
     Class<?> clazz = User.class;
     // 全限定类名（包名+类名）
     String fullName = clazz.getName();
     // 简单类名（仅类名）
     String simpleName = clazz.getSimpleName();
     // 是否是接口
     boolean isInterface = clazz.isInterface();
     // 是否是基本数据类型 int/boolean
     boolean isPrimitive = clazz.isPrimitive();
     // 获取父类Class对象
     Class<?> superClass = clazz.getSuperclass();
     // 获取实现的所有接口
     Class<?>[] interfaces = clazz.getInterfaces();
     ```

   - 

2. 获取权限修饰符 Modifier

   - Modifier 工具类解析修饰符数字，判断 public/private/static/final

   - ```java
     Field field = clazz.getDeclaredField("username");
     // 获取修饰符int编码
     int modifier = field.getModifiers();
     System.out.println(Modifier.isPrivate(modifier)); // true
     System.out.println(Modifier.isPublic(modifier));  // false
     System.out.println(Modifier.isStatic(modifier));  // false
     ```

   - 

3. 反射读取注解（框架核心，Spring 大量使用）

   - 自定义注解 + 反射读取示例：

   - ```java
     // 自定义注解
     @Target(ElementType.TYPE)
     @Retention(RetentionPolicy.RUNTIME)
     public @interface Table {
         String value();
     }
     
     // 使用注解
     @Table("t_user")
     public class User {}
     
     // 反射读取运行时注解
     Class<?> clazz = User.class;
     Table tableAnno = clazz.getAnnotation(Table.class);
     System.out.println(tableAnno.value()); // t_user
     ```

   - 注解必须标注 `@Retention(RetentionPolicy.RUNTIME)`，运行时才能通过反射获取；SOURCE/CLASS 级别注解反射拿不到





## 八、反射性能优化方案

1. 反射慢是硬伤，实际开发有 4 种优化手段：
   - 缓存反射元数据
     - 把 Class、Constructor、Method、Field 对象存入静态 Map，避免每次重复查找，Spring 底层大量缓存反射信息
   - 开启 setAccessible (true) 一次，复用对象
     - 不要每次调用反射都重复设置权限
   - 使用反射替代方案：LambdaMetafactory / 方法句柄 MethodHandle
     - JDK7 引入 MethodHandle，性能接近直接调用，比传统反射快很多
   - 编译期生成字节码（主流框架方案）
     - MyBatis、Spring、Hibernate 会使用 ASM、CGLIB、Javassist 字节码框架，动态生成代理类，代替运行时反射，大幅提升性能





## 九、反射经典应用场景

1. Spring IOC 容器
   - 读取 XML / 注解配置中的类全限定名，通过反射无参构造创建 Bean 对象，反射注入属性（依赖注入 DI）
2. Spring AOP 动态代理
   - JDK 动态代理底层依赖反射调用目标类方法；CGLIB 字节码代理作为补充
3. ORM 持久层框架 MyBatis/Hibernate
   - 读取数据库表和实体类映射关系，通过反射创建实体对象，反射给实体字段赋值查询结果
4. 单元测试框架 JUnit
   - 通过反射找到标注 @Test 的方法，运行时自动调用测试方法
5. 序列化 / 反序列化工具 Jackson、FastJSON
   - 反射读取对象所有字段，序列化为 JSON 字符串；解析 JSON 时反射创建对象、赋值字段
6. 通用工具类
   - 对象拷贝工具（BeanUtils）、通用 Excel 导入导出、通用反射分页查询
7. JDBC 数据库驱动加载
   - `Class.forName()` 反射加载驱动类，自动注册驱动





## 十、反射相关高频面试题总结

1. Class.forName 和 ClassLoader.loadClass 区别？
   - 答：前者会初始化类（执行静态代码块、静态变量赋值），后者仅加载字节码，不初始化
2. getMethod 和 getDeclaredMethod 区别？
   - 答：getMethod 只能获取本类 + 父类 public 方法；getDeclaredMethod 只能获取本类所有权限方法，不含父类
3. setAccessible (true) 作用，是否会破坏原类封装？
   - 答：关闭权限校验，允许操作私有成员；仅运行时临时生效，不会修改类源码字节码，不永久破坏封装
4. 反射为什么性能差？怎么优化？
   - 答：运行时解析元数据、权限校验、无编译优化；优化手段：缓存反射对象、MethodHandle、字节码生成代理
5. 反射能否操作静态变量 / 静态方法？
   - 答：可以，Field.set ()、Method.invoke () 第一个参数传入 null 即可
6. JDK9 为什么废弃 Class.newInstance ()？
   - 答：newInstance 只能调用无参构造，异常捕获繁琐；Constructor.newInstance () 支持有参构造，异常分层清晰，功能更全面





## 十一、反射底层原理极简说明

1. 类加载阶段：JVM 加载 class 字节码文件，解析类元数据，在堆中创建唯一 Class 对象
2. 反射代码执行时，通过 Class 对象读取内存中存储的构造器、字段、方法元数据
3. setAccessible (true) 修改底层 AccessFlag 访问标记，跳过安全校验
4. Method.invoke () 底层通过本地 native 方法，间接调用目标方法
