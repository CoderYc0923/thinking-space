## 过滤器（Filter）

1. Servlet 容器层，在 Spring MVC 之外
2. 适合：跨整个应用的横切能力（编码、CORS、日志、XSS、统一读 body）
3. 拿不到完整的 Spring MVC 能力（Handler、`@PathVariable` 等），和 Controller 耦合更弱

## 拦截器（Interceptor）

1. Spring MVC 层，在 DispatcherServlet 之后、进 Controller 之前
2. 适合：和业务路由相关的事——验 JWT、放行 `/login`、把用户 id 写入 `BaseContext`



|          | Filter       | Interceptor          |
| -------- | ------------ | -------------------- |
| 层级     | Servlet      | Spring MVC           |
| 典型用途 | 通用基础设施 | 登录鉴权、业务上下文 |
|          |              |                      |



**生产里最常见：Spring Security（底层是 Filter 链）**

1. 认证、鉴权、匿名放行、异常入口都挂在 Security Filter Chain 上
2. JWT 项目通常是自定义一个 `OncePerRequestFilter`（或 Security 的 JWT filter）塞进这条链，而不是用 MVC `HandlerInterceptor`
