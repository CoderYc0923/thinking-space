# 消息队列（学习笔记）

> 目标：把 **原理（通用）→ 选型（差异）→ 实操（生产）→ 面试（表达）** 串成一条线。  
> RocketMQ 深挖见已有长文；本目录先补「跨 MQ 共性」和「怎么讲清楚」。

---

## 建议阅读顺序

```text
00 为什么用 MQ          ← 场景、收益、代价（先建立问题空间）
01 通用原理             ← 推拉、ACK、顺序、幂等、堆积、事务…（换 MQ 也不变）
02 主流对比与选型       ← Kafka / RabbitMQ / RocketMQ / Redis Stream
03 实操与生产经验       ← 接入、监控、堆积、重复消费、排障清单
04 面试题精讲           ← 高频题 + 参考答法
消息队列详解-RocketMQ版 ← 架构、事务消息、部署与代码（单品深挖）
```

**和线上排查的关系**：MQ 出问题在用户侧多是「慢 / 超时 / 状态不对 / 重复处理」；落到中间件模块时，用本目录的堆积、消费失败、Broker 不可用等思路下钻。参见 [线上问题排查 · 中间件](../Java/进阶/线上问题排查/L3-模块/中间件/README.md)。
