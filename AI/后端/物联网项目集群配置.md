------

## 集群各自职责（一句话）

- MySQL（1 台）：业务主库，当前没开从库
- Redis（至少 3 台）：缓存 / 登录态 / 分布式锁（Cluster）
- RocketMQ（至少 2 台 NameServer）：异步消息；Broker 可能还在别的机器上，配置没列
- XXL-JOB（1 台调度中心）：定时任务调度
- 应用进程：admin（含 MQ 消费）、web、data，连上面这套中间件

------

## 不在这批内网机上的

- 阿里云 OSS（文件）
- 阿里云 RDS（旧系统库，data 模块用）
- HKT、短信等外部 API

------

最短结论： 生产中间件是「1 库 + 3 Redis + 2 MQ NameServer + 1 任务调度」拆在不同机器上；应用本机台数配置没写全。
