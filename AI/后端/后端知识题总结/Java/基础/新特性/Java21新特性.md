- **语言特性**

  - **Switch语句的模式匹配**

    - 允许在`switch`的`case`标签中使用模式匹配，使得操作更加灵活和类型安全

    - ```java
      switch
          case SavingAccount sa -> result = sa.getSavings();
      ```

  - **记录模式**

    - 将模式匹配扩展到记录类，允许在`instanceof`或`switch`中直接对`record`进行解构

    - ```java
      if (obj instanceof Point(int x, int y)) {...}
      // 可以直接把Point记录的组件结构到x\y变量中

  - **字符串模板**

    - 提供了一种更可读、更容易维护的方式来构建复杂字符串，支持在字符串字面量中直接嵌入表达式。需要通过模板处理器（如`STR`）调用，嵌入表达式使用`\{...}`

    - ```java
      STR."HELLO \{NAME}, WELCOME!";
      ```

- 并发特性

  - **虚拟线程**
    - 轻量级并发的新选择，它的栈在堆上动态分配，运行时挂载到平台载体线程(carrier thread)上执行，挂起时栈被卸载到堆中，因此可以创建大量虚拟线程而不消耗大量内存，显著提升了I/O密集型应用的吞吐量和响应速度。
    - 可以使用静态构建方法、构建器或`ExecutorServer`来创建和使用虚拟线程
  - **Scoped Values（范围值）**
    - 提供了一种在线程间共享不可变数据的新方法，避免使用传统的线程局部存储，促进了更好的封装性和线程安全，可用于在不通过方法参数传递的情况下，传递上下文信息，如用户会话或配置设置
