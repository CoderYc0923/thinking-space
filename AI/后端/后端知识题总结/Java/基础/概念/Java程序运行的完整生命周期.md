- 编译（运行前）
  - JDK中的`javac`编译器将`.java`源码编译成`.class`字节码文件
- 运行时（java启动进程）
  - 进入JRE：
    - **类加载器**按需从磁盘读取`.class`文件，把里面的类信息、字段、常量池以及各个方法的字节码装进内存。
    - 同时从Java类库里加载用到的标准类（如`String` `System` `I/O`等）
    - 然后**字节码验证器**校验字节码是否合法、安全
    - 然后做完**链接**和**初始化**
    - 到这里**类和方法字节码**已在**内存就位**，随后由 **JVM** 按方法执行。
  - 进入JVM：
    - JVM以内存中的**方法**作为执行单位，先看被调用的方法入口是否指向**Code Cache**（本地机器码缓存，加速执行）中的机器码，若是，直接执行
    - 若不是，则**解释器**逐条读取**该方法的字节码**，并分派到 JVM 里**已有的对应本地实现**去**执行**
    - 同时，JVM用**方法调用计数器**（以及方法内循环的**回边计数器**）累计方法调用次数
    - 运行期间，若**该方法调用次数**未达阈值，则继续用**解释器**解释执行
    - 若**本次调用**达到阈值，该方法会被**解释器**解释执行，同时**JIT即时编译器**将**该方法**编译成本地机器码，**写入Code cache并修改该方法入口指向Code cache**, 之后再调用则直接走机器码
    - 同时运行期间，**垃圾收集器**会回收**堆中**不再使用的对象，**线程与同步**会管理**并发**机制
