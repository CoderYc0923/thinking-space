- 共享变量（常加`volatile`或锁保证可见性），多线程读同一个共享变量来通信
- `wait / notify`等待和唤醒
- `Lock` + `Condition`（`await/signal`）类似等待和唤醒，只是等待可以分类，唤醒更精准更灵活
- 阻塞队列`BlockingQueue`（生产者消费者）
- 工具类：
  - `CountDownLatch`（等一批任务结束后），
    - 班长说：你们 3 个都做完再集合。每人做完按一次铃，铃响够 3 次，班长继续。
  - `CyclicBarrier`（等人齐），
    - 大家说好：人都到齐了再一起出发（可重复用）。
  - `Semaphore`（限流许可证）
    - 停车场只有 2 个车位：拿到票才能进，用完还票。用来限流。
