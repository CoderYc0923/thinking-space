- 指令重新排序
- 为了更快，编译器或CPU可能打乱代码的实际执行/生效顺序，只要在单线程里结果看起来和按书写顺序执行一样就行了



经典坑（和volatile相关）

- ```java
  // 线程A
  instance = new Singleton(); // 看似一步，实际可能：分配内存，写引用，初始化
  flag = true;
  
  // 线程B
  if (flag) {
      instance.use(); //若重排，可能flag已经是true，但对象还未初始化完
  }
  
  // volatile的一个作用就是：禁止这类危险重排，并建立happens-before，让【先写后读】在线程间有序可见
  ```
