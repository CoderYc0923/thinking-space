- final

  - 常量
  - 类不能继承、方法不能重写、变量不能赋值（引用不能换指向）

- static

  - 静态变量共享

- abstract

  - 抽象类/方法。
  - 不能直接new 
  - 和final不能一起修饰类

- synchronized

  - 同步锁/互斥锁，保证原子性和可见性

  - 原子性：（复合操作（如 `i++`、先读后写）不会被中间插进来打断）

  - 可见性：解锁前的写，对下一个获得锁的线程可见

  - ```java
    synchronized(obj) {};
    ```

- volatile

  - 可见性/有序关键字

  - 保证变量的可见性，并禁止指令重排序

  - 不保证复合操作的原子性

  - | 能保证                                       | 不能保证                                 |
    | -------------------------------------------- | ---------------------------------------- |
    | 一个线程改了，别的线程马上能看到最新值       | i++，if + set 这类读改写的复合操作原子性 |
    | 禁止部分重排（适合作开关，双重检查里的标志） | 代替锁区作复杂临界区                     |

  - 重排：

    - [重排](./重排.md)

- transient

  - 序列化时跳过该字段

- public/protected/private

  - 访问控制
  - public 全开放
  - protect 同包 + 子类
  - 默认 仅同包
  - private 仅本类

- extends/implements

  - 继承/实现

- this/super/new/instanceof

  - 当前对象/父类/创建类/类型判断
