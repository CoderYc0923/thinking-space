- 隐式转换
  - 当目标类型的范围大于源类型时，会自动转换为目标类型
  - 比如`int`转`long`，`float`转`double`
- 显示转换
  - 目标类型 变量名 = （目标类型）源类型
  - 但是范围大转范围小可能会出现数据溢出、精度丢失的问题



类型转换会出现什么问题吗？

- 基本数据类型转换问题

  - 大范围转小范围，会出现数据溢出或精度丢失
    - 比如 int 转bite 数据溢出，double转char精度丢失

- 对象引用转换的问题

  - 向上转型是安全的（隐式），但是向下转型有风险（显式）

    - 如果父类对象实际上并不是目标子类的实例，转型的时候会抛出异常classcastException

    - 向下转的时候需要用instanceof检查

      - ```java
        if (animal instanceof Dog) {
            Dog dog = (Animal) animal;
        }
        ```
