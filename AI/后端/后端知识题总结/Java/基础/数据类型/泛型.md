- 泛型指的是类/接口/方法上的参数类型，用的时候再指定具体类型

- ```java
  List<String> list = new ArrayList<>();
  <T extends Number> double add(T a, T b)
  ```



为什么要有？

- 复用：同一套逻辑服务多种类型，少写一堆重载
- 类型安全：编译器期检查，取出时少强转，减少`ClassCastException`
- 没有泛型时，List只能当Object容器，什么都能赛，取出来再自己转，容易转错



使用注意

- 只能用引用类型
  - 不能写 `List<int>`，要用 `List<Integer>`
- 类型擦除
  - 类型擦除 = 编译期用泛型做检查，生成字节码时去掉 `T`/`String` 这类参数，换成原始类型或上界，并在必要时插入强转——不是把 `T` 换成具体实际类型一直保留到运行时。
  - 编译后泛型信息基本擦成原始类型（如 `List` / 上界）；运行期一般拿不到 `T` 的具体类（除非反射保留了签名等）
- 不能new T() / new T[]
  - 擦除后编译器不知道具体类型
- 菱形<>
  - `new ArrayList<>()` 可由左边推断
