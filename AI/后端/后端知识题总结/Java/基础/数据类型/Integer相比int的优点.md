- Integer
  - 对象
  - 默认值null，可表示没有值
  - 能进集合/泛型，有工具方法
  - 自动拆装箱
- int
  - 基本类型
  - 默认值0
  - 只能存数值
- 能表示NULL、能进集合，是包装类相对基本类型的关键优势



那为什么还要保留int？

- 因为更快、更省
  - int变量直接存数值；Integer是对象，引用和对象分开存
  - 读写效率通常更高
  - 常见场景下一个int约4字节，一个Integer对象往往大约16字节量级（还包含对象头等）
- 原则:
  - 算术、局部变量、对性能敏感，用int
  - 要进集合/泛型、可能为空，用Integer
