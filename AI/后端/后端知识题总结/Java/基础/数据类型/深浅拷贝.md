- 浅拷贝
  - 只复制对象的字段值，引用地址不变
- 深拷贝
  - 对象的字段值、引用地址都变，生成一个新的对象

实现方式：

- 第三方库

  - Hutool `ObjectUtil.cloneByStream`
  - Apache Commons `SerializationUtils.clone`
  - MapStruct / 手写Bean拷贝时对嵌套对象再映射一遍

- 序列化（常用）

- 把对象状态写成一串字节，再按这串字节在内存里重建一个新对象（以及它引用到的对象图）。

- 优点：嵌套结构一次搞定。

- 缺点：要可序列化；`transient` 字段会丢（transient跳过序列化，该字段反序列化后是默认值）；性能一般。

- ```java
  ByteArrayOutputStream bos = new ByteArrayOutputStream();
  ObjectOutputStream oos = new ObjectOutputStream(bos);
  oss.writeObject(obj);
  
  ObjectInputStream ois = new ObjectInputStream(
  	new ByteArrayInputStream(bos.toByteArray())
  );
  Person copy = (Person) ois.readObject();
  ```

- 手动拷贝

- 自己 `new` 新对象，并把引用类型字段也递归拷一份。

- ```java
  class Address {
      String city;
      Address(String city) {this.city = city;}
      // 深拷贝用
      Address(Address other) { this.city = other.city; }
  }
  
  class Person {
      String name;
      Address addr;
      Person deepCopy() {
          Person p = new Person();
          p.name = this.name;
          // 别直接p.addr = this.addr
          // 用new 构造深拷贝
          p.addr = new Address(this.addr);
          return p;
      }
  }
  ```

- 重写clone（）

- 只调 `super.clone()` 不够深；坑多，很多项目不推荐依赖 `clone`。

- ```java
  // 实现Cloneable,super.clone()默认浅拷贝，引用字段要自己再深拷贝
  protected Object clone() throws CloneNotSupportedException {
      Person p = (Person) super.clone();
      p.addr = (Address) addr.clone(); // 引用也clone
      return p;
  }
  ```
