- new 关键字

  - JVM指令

  - 标准常用

  - 编译时必须知道具体的类名

  - ```java
    public class Person {
        private String name;
        
        public Person() {} // 默认构造器
        public Person(String name) { // 带参构造器
            this.name = name;
        }
        
        public void sayHello() {
            System.out.println("hello," + name);
        }
    }
    
    // 使用new
    public class Main {
        public static void main(String[] args) {
            Person p1 = new Person(); // 调用无参构造
            Person p2 = new Person("Cyrus"); // 调用有参构造
            
            p2.sayHello();
        }
    }
    ```

- 反射（newInstance）

  - 运行时类信息

  - 灵活，解耦，用于框架设计，如Spring的IOC容器、动态代理等。

  - 通过Java 反射API，在运行时动态创建对象。这种方式不需要在编译时知道具体的类

  - ```java
    Myclass obj = (MyClass) Class.forName("com.example.MyClass").getDeclaredConstructor().newInstance();
    ```

  - 注意：`Class.newInstance`在JDK9后被标记过时，因为它只能调用无参公有构造器，且会抛出所有受检异常。推荐使用`Constructor.newInstance()`

  - ```java
    Constructor<MyClass> constructor = MyClass.class.getConstructor();
    MyClass obj = constructor.newInstance();
    ```

- clone

  - 复制现有对象

    基于现有对象（原型）创建副本对象，通过实现`Cloneable`接口并重写`Object`类的`clone()`方法

  - ```java
    @Data
    public class Address implements Cloneable {
    	private String city;
        
        public Address(String city) {
            this.city = city;
        }
        
        @Override
        protected Address clone() throws CloneNotSupportedException {
            return (Address) super.clone(); // 浅拷贝
        }
    }
    
    // 实现Cloneable接口
    public class Person implements Cloneable {
        private String name;
        private Address address;
        // ...构造器和其他方法
        @Override
        protected Object clone() throws CloneNotSupportedException {
            Person cp = (Person) super.clone(); // 浅拷贝
           // 引用字段需要深拷贝
            cp.address = this.address.clone();
            
            return cp;
        }
    }
    
    public class Main {
        public static void main(String[] args) {
            Person p = new Person("Cyrus", new Address("Beijing"));
            try {
                Person cp = (Person) p.clone();
                cp.getAddress().setCity("Shanghai");
                
                p.sayHello(); // hello,Cyrus @ Beijing
                cp.sayHello();// hello,Cyrus @ Shanghai
            } catch (CloneNotSupportedException e) {
                e.printStackTrace();
            }
        }
    }
    ```

- 反序列化

  - 从字节流恢复

  - 用于持久化和网络通信，需实现Serializable

  - 通过`ObjectInputStream`从一个字节流（通常是文件或网络）中重建一个对象

  - ```java
    import java.io.*;
    
    // 必须实现Serializable接口
    public class Person implements Serializable {
        private String name;
        // ...构造器和其他方法
    }
    
    public class Main {
        public static void main(String[] args) {
            Person p = new Person("David");
            
            // 序列化对象到文件
            try (ObjectOutputStram oos = new ObjectOutputStream(new FileOutputStream("person.dat"))) {
                oos.writeObject(p);
            } catch (IOException e) {
                e.printStackTrace();
            }
            
            // 从文件反序列化对象
             try (ObjectInputStram ois = new ObjectInputStream(new FileInputStream("person.dat"))) {
                Person rp = (Person) ois.readObject(); // 创建新对象
                 rp.sayHello();
            } catch (IOException | ClassNotFoundException e) {
                e.printStackTrace();
            }
        }
    }
    ```

- 工厂模式

  - 设计模式，不直接使用new。通过方法返回对象实例。`Integer.valueOf()`,`Calendar.getInstance()`都是常见的工厂模式

  - 对象的创建和使用解耦，隐藏创建逻辑（如池化、缓存），控制实例

  - ```java
    public Class PersonFactory {
        private String name;
        
        // 构造器可以是私有的
        private Person(String name) {
            this.name = name;
        }
        
        public static Person createPerson(String name) {
            // 这里可以比如缓存、日志、返回子类实例等
            return new Person(name);
        }
    }
    
    public class Main {
        public static void main(String[] args) {
            Person p = PersonFactory.createPerson("Eva");
            p.sayHello();
        }
    }
    ```
