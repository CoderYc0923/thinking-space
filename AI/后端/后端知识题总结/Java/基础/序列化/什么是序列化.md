- **总结**

  - 序列化/反序列化就是对象和字节之间的转换。为了方便存储和跨`JVM`传输。而Java原生序列化`Serializable` + `ObjectOutpitStream / ObjectInputStream`（`static / transient`默认不进序列化）存在不跨语言、不安全、偏大的问题，生产更常用`Protobuf / JSON`等。

- `JSON`一般用`jackson`

  - 适用于**HTTP接口、配置、日志**

  - ```java
    import com.fasterxml.jackson.databing.ObjectMapper;
    
    @Data
    public class User {
        private String name;
        private int age;
        
        public User() {}
        
        public User(String name, int age) {
            this.name = name;
            this.age = age;
        }
    }
    
    // 使用
    ObjectMapper mapper = new ObjectMapper();
    
    // 序列化
    User user = new User("Tom", 18);
    String json = mapper.writeValueAsString(user);
    // 输出：{"name":"Tom","age":18}
    
    // 反序列化
    User u = mapper.readValue(json, User.class);
    u.getName();
    u.getAge();
    ```

- `Protobuf`跨语言，性能高

  - 适用于`RPC`、多语言、要省宽带

  - ```java
    // 1 定义user.proto
    syntax = "proto3";
    option java_package = "com.example";
    option java_outer_classname = "UserProto";
    
    message User {
        String name = 1;
        int32 age = 2;
    }
    
    // 2 用protoc（或Maven/Gradle插件）生成Java代码后
    
    // 序列化
    UserProto.User user = UserProto.User.newBuilder()
        	.setName("Tom")
        	.setAge(18)
        	.build();
    
    byte[] bytes = user.toByteArray();
    
    // 反序列化
    UserProto.User u2 = UserProto.User.parseFrom(bytes);
    System.out.println(u2.getName()); // Tom
    
    ```
