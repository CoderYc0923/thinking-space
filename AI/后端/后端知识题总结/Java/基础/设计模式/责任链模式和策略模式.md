- **责任链模式和策略模式**都属于**行为型模式**，一般都是为了解决：**如何消除代码中复杂的`if-else`或`switch case`逻辑，从而让系统更易扩展**



- **区别**
  - **策略模式**：多选模式，选一个执行完就结束
  - **责任链模式**：链式调用，层层处理。



- **策略模式**

  - 同一类事有多种做法（支付、折扣、排序...），每种做成一类，都实现统一接口。业务只依赖接口，运行时换成具体实现

  - 结构：**策略接口 + 多个策略 + 上下文（持有当前策略并调用）**

  - **适用于多种算法/行为**

  - ```java
    // 策略接口
    interface PayStrategy {
        void pay(int amount);
    }
    
    class AlipayStrategy implements PayStrategy {
        public void pay(int amount) { /* 调支付宝 API */ }
    }
    
    class WechatPayStrategy implements PayStrategy {
        public void pay(int amount) { /* 调微信 API */ }
    }
    
    // 上下文
    class PayContext {
        private PayStrategy strategy;
        public PayContext(PayStrategy strategy) { this.strategy = strategy; }
        public void execute(int amount) { strategy.pay(amount); }
    }
    
    // 使用：按用户选择换策略，而不是一堆 if
    PayStrategy s = "alipay".equals(type) ? new AlipayStrategy() : new WechatPayStrategy();
    new PayContext(s).execute(100);
    ```

- **责任链模式**

  - 请求**沿着一条链往下传**：**当前节点能处理就处理**（或处理完再传），**不能就交给下一个**。发送方只**认识链上第一个节点**。

  - 结构：**`抽象 Handler（持有 next）` + `多个具体 Handler` + 组装顺序**

  - 类似：请假审批，经理 → 总监 → 总经理，天数不够权限就继续往上递。

  - **适用于多个对象都可能处理同一请求、发送者不想和具体处理者耦合、处理步骤要能增删、调顺序（Spring 过滤器/拦截器、Netty Pipeline 都是这味道）**

  - ```java
    // 接口校验
    abstract class Handler {
        protected Handler next;
        public Handler setNext(Handler next) {
            this.next = next;
            return next;
        }
        public abstract boolean handle(Request req);
    }
    
    // 登录校验
    class LoginHandler extends Handler {
        public boolean handle(Request req) {
            if (!req.isLogin()) return false;          // 拦住
            return next == null || next.handle(req);   // 放行给下一个
        }
    }
    
    class AuthHandler extends Handler { /* 校验权限，同理 */ }
    class RateLimitHandler extends Handler { /* 限流，同理 */ }
    
    
    // 使用：组装校验链：登录 → 权限 → 限流
    Handler chain = new LoginHandler();
    chain.setNext(new AuthHandler()).setNext(new RateLimitHandler());
    
    // 业务只调用链头
    boolean ok = chain.handle(request);  // 只调链头
    ```
