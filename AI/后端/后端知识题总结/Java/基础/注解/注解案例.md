# 注解案例：@AddLog 记方法调用次数

思路：注解还是同一个；用 `@Aspect` 拦截「带 @AddLog 的方法」，不必手写 Proxy。

### 0. 依赖

```xml
<!-- pom.xml -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-aop</artifactId>
</dependency>
```

（`spring-boot-starter-aop` 会带上 aspectjweaver，并自动开启代理。）

### 1. 注解

```java
package com.example.demo.addlog;

import java.lang.annotation.*;

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface AddLog {
    String value() default "";
}
```

### 2. AOP切面拦截注解进行实现

```java
package com.example.demo.addlog;

import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.reflect.MethodSignature;
import org.springframework.stereotype.Component;

import java.lang.reflect.Method;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicInteger;

@Aspect
@Component
public class AddLogAspect {

    private static final Map<String, AtomicInteger> COUNTER = new ConcurrentHashMap<>();

    /** 拦截所有带 @AddLog 的方法 */
    @Around("@annotation(com.example.demo.addlog.AddLog)")
    public Object around(ProceedingJoinPoint pjp) throws Throwable {
        Method method = ((MethodSignature) pjp.getSignature()).getMethod();
        // 注解可能在接口方法上，实现类上取更稳
        Method targetMethod = pjp.getTarget().getClass()
                .getMethod(method.getName(), method.getParameterTypes());
        AddLog addLog = targetMethod.getAnnotation(AddLog.class);
        if (addLog == null) {
            addLog = method.getAnnotation(AddLog.class);
        }

        if (addLog != null) {
            String key = pjp.getTarget().getClass().getSimpleName() + "#" + method.getName();
            int n = COUNTER.computeIfAbsent(key, k -> new AtomicInteger()).incrementAndGet();
            String tag = addLog.value().isEmpty() ? key : addLog.value();
            System.out.println("[AddLog] " + tag + " 第 " + n + " 次调用");
        }

        return pjp.proceed(); // 执行原方法
    }

    public static Map<String, AtomicInteger> getCounter() {
        return COUNTER;
    }
}
```

### 3. Service（Spring 管理 Bean，注入时已是代理）

```java
package com.example.demo.service;

import com.example.demo.addlog.AddLog;
import org.springframework.stereotype.Service;

@Service
public class OrderService {

    @AddLog("下单")
    public void placeOrder(String orderId) {
        System.out.println("  [业务] 下单: " + orderId);
    }

    public void cancelOrder(String orderId) {
        System.out.println("  [业务] 取消: " + orderId);
    }
}
```

### 4. 调用（Controller / 别的 Bean 注入）

```java
package com.example.demo.web;

import com.example.demo.addlog.AddLogAspect;
import com.example.demo.service.OrderService;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class OrderController {

    private final OrderService orderService;

    public OrderController(OrderService orderService) {
        this.orderService = orderService; // 注入的是 Spring AOP 代理
    }

    @GetMapping("/order")
    public String order() {
        orderService.placeOrder("A001");
        orderService.placeOrder("A002");
        orderService.cancelOrder("A001");
        return AddLogAspect.getCounter().toString();
    }
}
```
